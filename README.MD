# Телеграмм бот для уведомлений о проверке работ

Программа отправляет информацию о результатах проверки задания на онлайн курсах "Devman"

## Переменные окружения

Для корректной работы программы вам понадобится вводить данные от Телеграмм бота, Айди вашего чата и ваш персональный токен от devman:
1. CHAT_ID - Это айди вашего чата в телеграмме, для того чтобы взаимодействовать с API 
2. TG_TOKEN - Персональный токен от Телеграмм бота. Это по сути, ключ доступа к его управлению
3. DVMN_ACCESS_TOKEN - Это Токен от API девмана, доступного исключительно студентам курсов. 

## Зависимости, которые понадобятся для работы:

- `requests==2.31.0`
- `pyTelegramBotAPI==4.35.0`
- `python-dotenv==1.0.0`

## Что надобится для работы: 

- Переходим на сайт [Документация API DVMN](https://dvmn.org/api/docs/) и копируем персональный токен
- Открываем телеграмм, и ищем бота BotFather - Это отец всех ботов телеграмма. У него ваш необходимо получить токен от бота
- Снова открывает телеграмм, открываем бота [@userinfobot](https://t.me/userinfobot) и узнаем свой chat_id. Он нужен телеграмму чтобы бот отправлял конкретно вам сообщения 

## Установка

python 3.10 уже должен быть установлен на вашем компьютере. После установки репозитория на ваш компьютер открываем его в любом редакторе кода, переходим в коммандую строку и пишем:
- `pip install -r requirements.txt` - Комманда установит всех необходимые зависимости для корректной работы программы
- Открываем файл .env и вносим в него все переменные окружения, которые были получены шагом выше.
  Пример:

  `TG_TOKEN='Ваш_Телеграм_токен'`


## Запуск

Послe получения переменных окружения, их внесения, установки зависимостей вы можете запускать бота коммандой:
- `python check_review_bot.py`
